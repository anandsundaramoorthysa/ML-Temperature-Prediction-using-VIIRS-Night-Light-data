Research Objective

This project demonstrates how urbanization influences local climate by predicting average monthly temperature using Year, Month, and VIIRS Nighttime Light intensity as inputs. Monthly resolution provides more data points and reduces overfitting. Nightlight intensity serves as a proxy for human activity patterns.

Key Findings

Human Activity Proxy

VIIRS monthly nighttime light intensity is used as an indicator of human activity patterns

Temperature Prediction

Multiple ML models successfully predict monthly temperature based on year, month, and human activity patterns

Model Performance

All models show significant predictive power, with {% if best_model %}{{ best_model }}{% else %}Gradient Boosting{% endif %} performing best

Human Activity Impact

Analysis reveals association between human activity (monthly nightlights) and local temperature patterns

Important Academic Disclaimer

This analysis demonstrates ASSOCIATION and INFLUENCE, NOT CAUSATION. While we observe relationships between urbanization indicators and temperature, correlation does not establish causal mechanisms. Other factors such as global climate change, natural variability, and regional patterns may contribute to observed relationships.

Methodology Overview

1. Data Preprocessing

Validated and aggregated temperature data to monthly averages (2014-2024), merged with monthly nightlight data

2. Exploratory Analysis

Analyzed relationships using visualizations and correlation analysis

3. Model Training

Trained three models (Multiple Linear Regression, Random Forest, Gradient Boosting) using Year, Month, NightLight features with time-based split

4. Evaluation

Compared models using RMSE, MAE, and R² metrics with overfitting detection (training vs testing)

5. Interpretation

Analyzed feature importance (Year, Month, NightLight) to understand human activity's contribution
