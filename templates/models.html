Model Selection Rationale

Three different machine learning approaches were trained and compared:

Multiple Linear Regression

Type: Multiple Linear Regression (3 features: Year, Month, NightLight)

Equation: Temperature = β₀ + β₁×Year + β₂×Month + β₃×NightLight

Baseline model with interpretable coefficients. Assumes linear relationships between features and target.

Random Forest

Ensemble method handling non-linear relationships and feature interactions.

Gradient Boosting

Sequential learning approach often achieving high predictive performance.

Evaluation Metrics Explained

RMSE

Root Mean Squared Error: Average prediction error in °C. Lower is better. Penalizes large errors more heavily.

MAE

Mean Absolute Error: Average absolute error in °C. Lower is better. All errors weighted equally.

R² Score

Coefficient of Determination: Proportion of variance explained. Ranges from 0 to 1 (1 = perfect). Higher is better.

Model Limitations
  • Moderate dataset size (132 monthly observations) still limits statistical power, though improved from 12 yearly observations
  • Models trained on historical data may not generalize to future scenarios
  • Multiple Linear Regression assumes linear relationships between all features (Year, Month, NightLight) and may not capture complex non-linear patterns
  • Time-based split (80% training, 20% testing) prevents data leakage and simulates real-world prediction
  • Models use regularization to control overfitting risk
  • All models assume relationships can be captured by current features
